# 按模块管理项目

用这个 skill 让 Codex 熟悉你的项目。它会按项目的实际功能整理说明，以后你提需求时，Codex 就能找到相关代码和开发约定。

## 第一次使用

1. 在 Codex 中打开你要整理的项目文件夹。
2. 在聊天里发送下面这句话。

   > 使用 $modular-project-skills 为当前项目建立按模块维护的项目说明。

3. 完成后，打开项目首页的 `README.md`，查看项目用途和使用方法。项目根目录还会有一份给 Codex 看的 `AGENTS.md`，引导它按任务查阅对应模块的说明。

以后在这个项目里新开聊天，直接描述你想做的事就行。
